# VARCO 3D

[VARCO 3D](https://3d.varco.ai) MCP는 열려 있는 **플로우 편집기**를 통해 동작합니다. 이 플러그인은 그 편집기를 **OMP Studio 안 숨은 창**에 띄워 두어, 브라우저를 열지 않아도 AI가 `varco-3d` MCP로 3D를 생성할 수 있게 합니다.

## 준비
1. MCP 서버 `varco-3d`를 등록합니다 (설정 → MCP): `{"type": "http", "url": "https://3d.varco.ai/api/mcp"}`.
2. 사이드바 **VARCO 3D**를 눌러 숨은 창에서 VARCO 계정으로 **한 번 로그인**합니다. 이후로는 자동입니다.

## 동작
- OMP Studio가 켜지면 마지막에 쓰던 플로우를 자동으로 엽니다(없으면 새로 만듦).
- 창을 닫으면 숨겨질 뿐 연결은 유지되고, 편집기가 죽거나 로딩에 실패하면 자동으로 다시 엽니다.
- 로그인이 풀리면 로그인 창이 뜨고, 로그인 후 다시 숨겨져 연결됩니다.

## 사이드바 VARCO 3D
버튼을 누르면 편집기 창이 앞으로 뜨고, 화면에서 연결 상태·남은 포인트·플로우 목록을 보고 **이 플로우로 전환**, **새 플로우**, **창 숨기기**를 할 수 있습니다.

## AI 도구 `varco3d_editor`
| action | 하는 일 |
|---|---|
| `open {flowId?}` | 플로우를 열고 MCP가 인식할 때까지 기다린 뒤 flowId 반환 |
| `new {name?}` | 새 플로우를 만들어 열기 |
| `status` | 로그인·포인트·MCP 세션 상태 |
| `show` / `hide` | 사람이 편집기를 보거나 숨기기 |

에이전트 지침 예: "`list_flow_sessions`가 비어 있으면 `varco3d_editor {action:"open"}`을 호출한 뒤 반환된 flowId로 작업하라."

> 같은 플로우를 브라우저에서도 열면 편집 권한이 충돌할 수 있습니다. 직접 보려면 사이드바 버튼을 쓰세요.
